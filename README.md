# LED — сайт на Next.js

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Перед запуском в продакшн

1. **Formspree** — впишите свой ID формы в `src/lib/site.ts`:
   ```ts
   formspreeEndpoint: "https://formspree.io/f/YOUR_FORM_ID",
   ```
   Зарегистрируйте форму на https://formspree.io — оба поп-апа («Оставить заявку»
   в шапке/слайдере/на странице товара и форма внизу сайта) уже отправляют письма
   на этот endpoint. Формы настроены на отправку на *******@gmail.com — при
   создании формы в Formspree укажите этот email как получателя.

2. **Фото «Наши работы»** — положите файлы (jpg/png/webp) в `public/works/`.
   Они автоматически появятся в разделе «Наши работы» на главной. Подписи
   добавляются вручную в `src/components/OurWorks.tsx`, если нужны.

3. **Сертификат** — положите файл `certificate.jpg` (или .png/.pdf) в `public/`.
   Он автоматически подхватится в разделе «Наш сертификат».

4. **Товары** — все ~80 позиций описаны в `src/data/products.ts`. Названия
   серий соответствуют реальным линейкам (взяты из URL источников, которые вы
   присылали), характеристики (шаг пикселя, яркость, IP и т.д.) сгенерированы
   по типовым для отрасли диапазонам для каждой категории — при необходимости
   уточните точные цифры по конкретным моделям и подставьте вручную в этот файл.
   Категории — в `src/data/categories.ts`.

5. **Деплой** — проще всего на Vercel: `vercel` в терминале проекта, либо
   через импорт репозитория на vercel.com.

## Структура

- `src/app` — страницы (главная, /categories, /category/[slug], /product/[slug], /search)
- `src/components` — вся вёрстка (шапка, слайдер, карточки, формы, футер)
- `src/data` — каталог товаров и категорий
- `public/works` — фото для раздела «Наши работы»
- `public/certificate.*` — файл сертификата
